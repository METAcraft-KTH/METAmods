# SplatCraft RP by SculK3d

Resource pack from the "SplatCraft Map + RP" bundle ("Splatoon 3 by Newalbacore8" world + "SplatCraft RP by SculK3d"), licensed LGPLv3 (see LICENSE.LGPL-3.0). Kept here as source material for Metacraft Rivals: the squid item model (carved_pumpkin*.json, 32x32 textures), the splat bomb model (snowball*.json), the ink tank textures. The map itself is used only as a private test arena (run-v6/world-splat), not redistributed.
